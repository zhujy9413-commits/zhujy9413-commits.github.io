# 朱家毅的个人主页

地址：https://zhujy9413-commits.github.io/

基于 https://github.com/wwbtq/bento-portfolio-template 的布局、样式与交互进行个人内容适配。
个人内容配置：`js/data.js`。作品卡片使用 `js/data.js` 中的 `projects` 配置，整卡直接跳转对应 GitHub 仓库。无真实资料的技能与经历模块暂不展示。
联系表单通过本机邮件客户端发送，无服务端收件功能。

首页分类为 Tools（Skills）、AI（应用与 Agent）、Fun（游戏与创作实验）、Ideas（文章与思考）。项目按 `projects[].group` 归类；每个项目只展示一次，点击整卡直达 GitHub。
